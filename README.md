## 🚀 AuraLock

### Intentional Technology for Focus

**AuraLock** is an Android application designed to help people create a more intentional relationship with their phones.

It combines intentional phone use, focus sessions, goals, journaling, meditation, challenges, achievements, and an intelligent on-device assistant into one privacy-first experience.

**Core principles:**

* Privacy-first and local-first
* No account required
* No unnecessary cloud dependency
* Designed around intentional phone use
* Built for a simple, focused experience
